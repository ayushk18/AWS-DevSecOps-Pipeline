## 🔄 CI/CD Pipeline (GitHub Actions)

### Workflow File: `.github/workflows/docker-push.yml`

**Trigger Events**:
- Push to `main` branch
- Create git tags matching `v*` (v1.0.0, v1.1.0, etc.)
- Manual trigger via GitHub Actions UI

**Three Main Jobs**:

#### 1. **Build and Push Docker Image** (1-2 minutes)
```yaml
Job: push-docker
- Checkout code
- Setup Docker Buildx (advanced build engine)
- Login to GitHub Container Registry (GHCR)
- Extract metadata (tags, labels)
- Build and push image to ghcr.io
- Generate summary output
```

**Pushed To**: `ghcr.io/ayushk18/aws-devsecops-pipeline`

**Tags Generated**:
- `main` (branch name)
- `sha-abc123def` (commit SHA)
- `latest` (always latest)

#### 2. **Scan Image with Trivy** (1-2 minutes)
```yaml
Job: scan-image (runs after push-docker)
- Run Trivy vulnerability scanner
- Generate SARIF report (GitHub Security format)
- Upload results to GitHub Security tab
```

**Scanners Integrated**:
- **Trivy**: Container vulnerability scanning
- **gitleaks**: Secret detection (in code)
- **bandit**: Python code security analysis
- **OWASP ZAP**: Dynamic security testing (simulated)

#### 3. **Workflow Summary** (logs results)
```yaml
Job: notify (runs after both jobs complete)
- Generate comprehensive summary
- Report job status
- Provide links to packages and security tabs
- Alert on failures
```

## 🛠️ Troubleshooting Reference

### Issue: Workflow Fails on Push

**Symptom**: Actions job shows red ❌

**Check**:
1. Click failing job in Actions tab
2. Scroll to error message
3. Common causes:
   - Dockerfile syntax error
   - Missing `requirements.txt`
   - Git credentials issue (unlikely for public repos)
   - Disk space on GitHub runner (rare)

### Issue: Image Not Appearing in Packages

**Symptom**: `docker pull` fails

**Check**:
1. Verify workflow passed (green ✅)
2. Wait 1-2 minutes for GHCR sync
3. Check repository visibility (public vs private)
4. Verify you're using correct image name: `ghcr.io/ayushk18/aws-devsecops-pipeline`

### Issue: Trivy Scan Missing

**Symptom**: No results in Security tab

**Check**:
1. Verify scan-image job ran successfully
2. Check SARIF file was generated (logs show: "Validating trivy-results.sarif")
3. Ensure `permissions: security-events: write` is set in workflow

## 📚 Key DevSecOps Concepts Implemented

### 1. **Infrastructure as Code**
- Dockerfile defines deployment spec
- GitHub Actions defines CI/CD
- Reproducible builds

### 2. **Shift Left Security**
- Scan at every stage (build, push, runtime)
- Fail fast on critical vulnerabilities
- Automate security checks

### 3. **Container Security**
- Minimal base image (slim)
- Health checks
- Non-root user (best practice)
- Vulnerability scanning (Trivy)

### 4. **Secret Management**
- Use GitHub Secrets for credentials
- Environment variables via `.env`
- Detect secrets in code (gitleaks)

### 5. **Continuous Deployment**
- Automated builds on push
- Consistent image tagging
- Central registry (GHCR)
